# How-to guides

Recipes for the changes that come up again and again. Each one lists the files to touch, the
checks to run, and the docs pages to update with it.

- [Add a link profile](add-link-profile.md): a published downlink budget for another satellite.
- [Add a packet template](add-packet-template.md): let comms talk to another satellite.
- [Change the WebSocket contract](change-ws-contract.md): a new field or message, safely.
- [Add a setting](add-setting.md): a new `SATLAB_*` environment variable.
- [Add a migration](add-migration.md): change the schema without breaking the running code.
- [Add a satellite type rule](add-type-rule.md): classify satellites differently.
- [Deploy and roll back](deploy-and-rollback.md): from `dev` to production, and back.
- [Write the docs](write-docs.md): how this site is built and kept in sync.
